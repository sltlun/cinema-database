# База данных «Кинотеатры Санкт-Петербурга»

Индивидуальная курсовая работа по проектированию и разработке реляционной базы данных в PostgreSQL.

## Цель проекта

Разработать базу данных для хранения и обработки информации о кинотеатрах, фильмах, сеансах, зрителях и продаже билетов.

## Описание

В рамках проекта разработана реляционная база данных, состоящая из 6 связанных таблиц:

- `cinemas` — информация о кинотеатрах;
- `movies` — информация о фильмах;
- `sessions` — расписание киносеансов;
- `spectators` — информация о зрителях;
- `tickets` — билеты на сеансы;
- `orders` — заказы билетов.

Реализованы первичные и внешние ключи, ограничения целостности и индексы.

Написаны аналитические SQL-запросы для расчёта выручки, анализа продаж и стоимости билетов.

## Используемые технологии

- PostgreSQL
- SQL
- pgAdmin 4

## Аналитические запросы

В файле `queries.sql` представлены:

1. Анализ выручки и количества проданных билетов по фильмам.
2. Определение пяти сеансов с наибольшей выручкой.
3. Анализ средней, минимальной и максимальной стоимости проданных билетов по кинотеатрам.
4. Анализ продаж билетов по кинотеатрам, включая выручку и долю проданных билетов.

В запросах используются `JOIN`, `GROUP BY`, `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `CASE`, `CTE` и `FILTER`.
